# Pumpkin Panic

Hey! This is my Halloween game I made with p5.js. You play as a pumpkin and try to grab as much candy as you can while ghosts are trying to haunt you. It's harder than it looks, I promise.

## How to Play

- Move the pumpkin with your mouse, your finger (on a phone), or the left and right arrow keys (A and D work too)
- Catch the candy to get points
- Dodge the ghosts because every time one hits you, you lose a life
- You have 3 lives. When they're gone, it's game over
- Click, tap, or press SPACE to start and to play again

## How to Run It

1. Save the code as `pumpkin-panic.html`
2. Double click it to open it in your browser
3. Play!

You need internet the first time because the game loads p5.js from the web.

## Stuff I Used

- p5.js (for drawing everything)
- HTML and JavaScript
- No images at all. I drew the pumpkin, ghosts, bats, and tombstones with shapes in code, which was kind of fun
